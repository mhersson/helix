# Helix

This is the documentation for a personal fork of the Helix editor. It adds
in-buffer Markdown rendering and a handful of upstream pull requests on top
of Helix.

Everything good in this editor starts with the Helix editor project and its
many contributors. The fork branched from upstream commit `ba40e5474`
(2026-09-29) and picks individual upstream changes when they are wanted.

See the [usage] section for a quick overview of the editor, [keymap]
section for all available keybindings and the [configuration] section
for defining custom keybindings, setting themes, etc.
